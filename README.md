# 无人机装调与故障检修箱

面向无人机装调、故障检修与实训的硬件及控制程序项目。

本仓库整理了检修箱的电路设计、STM32 控制程序、结构加工图、串口通信资料及使用说明。当前资料来自开发阶段归档，工程路径、构建环境和版本对应关系仍在整理中。

## 项目组成

| 部分    | 内容                                       |
| ----- | ---------------------------------------- |
| 电路设计  | 检修箱控制环原理图，以及主控层、继电层、过渡层等 PCB 设计          |
| 控制程序  | 两套基于 STM32 的 Keil 工程，原目录分别命名为“上位机”和“下位机” |
| 电脑端软件 | `DroneSetup.msi` 安装包，当前资料中未包含明确对应的桌面软件源码 |
| 机械资料  | 加工图及 GY-M30 公座、母座 DXF 图纸                 |
| 接口与通信 | 硬件资源对照表、针脚定义、串口指令定义及通信时序图                |
| 使用资料  | 过流测试板使用说明、测试耗材单及研发记录                     |

> 本项目中名为“上位机”的代码目录实际也是 STM32 单片机工程。两套程序的具体职责与连接关系将在后续文档中补充说明。

## 电路设计

电路设计源文件为：

```text
无人机故障检测维护实训箱.eprj2
```

该工程包含“故障检修箱控制环”原理图，以及以下 PCB 文档：

- 主控层
- 主控层（模块丝印）
- 继电层
- 继电器单体模块
- 过渡层

目录中的 `SCH_*.png` 和 `2D_*.png` 为原理图、PCB 预览，修改设计时应使用原始工程。

当前资料中尚未提供独立的 Gerber、钻孔及贴片坐标导出包。用于制造的文件及对应硬件版本将在后续整理。

## 控制程序

两套程序的工程入口分别为：

```text
故障检修箱 上位机/标准库/project.uvprojx
故障检修箱下位机/标准库/project.uvprojx
```

工程内主要目录：

| 目录                     | 用途               |
| ---------------------- | ---------------- |
| `User/`                | 主程序及相关配置         |
| `Function/`            | 串口、定时器、显示及业务控制代码 |
| `Library/`             | STM32 外设库        |
| `StartUp/`             | 启动文件与内核相关代码      |
| `Objects/`、`Listings/` | 编译输出、固件及构建报告     |

目前两个工程的目标器件均配置为 `STM32F103C6`，部分开发记录中提及 `STM32F103C8T6`。实际使用的芯片型号及对应工程配置需要进一步统一。

工程中还存在指向原开发电脑 E 盘的源文件引用。迁移到其他电脑时，需要核对这些引用并改为项目内的相对路径。

以下构建信息待补充：
